# vehicle module

- Driving physics, traffic AI, theft, damage and rendering are our own implementation in `dev.leonida.vehicle`.
- Immersive Vehicles (MTS) was decompiled only as a reference for how a vehicle mod structures seats, controls
  and part rendering. No code, models or textures were copied from it.
- Immersive Aircraft (GPL) was read only as a reference for the Minecraft entity rendering API
  (custom geometry submission). No code was copied from it.
- All vehicle models are built from code-generated cuboids (`render/Body.java`, `render/Parts.java`,
  `render/FleetCars.java`, `render/VehicleModels.java`). The texture atlas is generated by our own script
  (`render/gen_atlas.py`). Sounds are original or generated.
- Vehicle names follow the fictional brands and models seen in the published GTA VI trailers (fan notes in
  VEHICLES.md). No real car-maker or game-studio logos are used; badges, plates ("Leonida") and liveries
  (VCPD, Leonard County Sheriff) are our own simplified artwork.
