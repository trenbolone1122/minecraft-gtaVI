Leonida Shaders
An original Iris/OptiFine format shader pack made for the Leonida Minecraft mod: Florida sun path, physically inspired
sky with golden hour and pink dusk, cumulus clouds, soft shadows, haze, filmic tonemap, bloom, water with depth colour
and foam, screen space reflections, labPBR normal and specular maps, character rim light.
Copyright trenbolone1122. License: GNU GPL 3.0 or later (same as the Leonida mod). No code from other shader packs.
The ACES curve fit in lib/tonemap.glsl is the public approximation by Krzysztof Narkowicz.
The mod copies this folder to .minecraft/shaderpacks on launch; edit config/leonida-shader.properties to opt out.
